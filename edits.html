01

How we handle changes

Correction
A fact, figure or source was wrong. We fix it on the page and note the original error here.
Update
Newer data or a newer document replaced an older one.
Clarification
Wording was changed to be clearer or more precise, without changing the facts.

Spelling, layout and link fixes that do not change meaning are not listed. To suggest a correction, use the contact form.
